# Examples

`input/official_catvrs_example.json` is a small pipeline fixture derived from the
official Cat-VRS canonical allele example for ClinGen CA415424538:

<https://cat-vrs.ga4gh.org/en/1.1.0/examples/canonicalAllele-ex2.html>

The VRS identifiers, digests, coordinates, and reference sequence accessions are
supplied by that example. They were not generated or repaired in this repository.

`output/pilot/` contains deterministic demonstration output generated with seed
`20260925`. Its answer-key annotation tests identifier recovery only and is not a
clinical interpretation.
